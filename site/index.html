βάθος

Turn one Claude Code session into a disciplined, exceptional product team.

하나의 Claude Code 세션을 절제되고 탁월한 제품 팀으로.

Convierte una sola sesión de Claude Code en un equipo de producto disciplinado y excepcional.

BATHOS is an AI Workflow Agent method of overwhelming depth — 16 specialist roles, a 7-wave delivery pipeline, scale-adaptive routing, and hard quality gates, backed by a small Rust engine that makes the critical invariants deterministic instead of vibes.

BATHOS는 압도적 깊이의 AI Workflow Agent 메서드입니다 — 17개 전문 역할, 7웨이브 딜리버리 파이프라인, Scale-Adaptive 라우팅, 하드 품질 게이트, 그리고 핵심 불변식을 vibes가 아니라 결정적으로 만드는 작은 Rust 엔진.

BATHOS es un método de AI Workflow Agent de profundidad abrumadora — 17 roles especialistas, un pipeline de entrega de 7 waves, enrutamiento scale-adaptive y gates de calidad estrictos, respaldado por un pequeño motor en Rust que vuelve deterministas los invariantes críticos en lugar de dejarlos al instinto.

01 · two planes01 · 두 실행면01 · dos planos

A method on top, a deterministic engine underneath.

상부는 메서드, 하부는 엔진을 통한 Harnessing.

Un método arriba, un motor determinista debajo.

In practice you mostly type slash commands. Beneath them sits the bathos binary — the deterministic core those commands and hooks invoke, and where trust actually lives: unit-tested, and impossible to talk your way past.

당신이 손으로 치는 건 대개 슬래시 커맨드입니다. 그 아래에 bathos 바이너리가 있습니다 — 커맨드와 훅이 불러 쓰는 결정적 코어이자, 신뢰가 실제로 사는 곳입니다. 단위 테스트로 검증되고, 말로는 우회할 수 없습니다.

En la práctica, lo que tecleas son sobre todo slash commands. Bajo ellos está el binario bathos — el núcleo determinista que esos comandos y hooks invocan, y donde reside de verdad la confianza: verificado con tests unitarios e imposible de sortear con labia.

03 · scale-adaptive

Run only the waves the task needs.

작업이 필요한 웨이브만 실행.

Ejecuta solo las waves que la tarea necesita.

The router recommends a level from four stakes axes; you confirm (User Sovereignty). A bug fix isn't dragged through full discovery; an enterprise build isn't under-scoped.

라우터가 4개 stakes 축으로 레벨을 추천하고, 당신이 확정합니다(User Sovereignty). 버그 수정을 풀 디스커버리에 끌고 가지 않고, 엔터프라이즈 빌드를 과소 스코핑하지 않습니다.

El router recomienda un nivel a partir de cuatro ejes de stakes; tú lo confirmas (User Sovereignty). Un arreglo de bug no se arrastra por un descubrimiento completo; una build empresarial no se queda corta de alcance.

04 · quality gates04 · 품질 게이트04 · gates de calidad

One vocabulary. No evidence-free auto-pass.

단일 용어. 근거 없는 자동 PASS 없음.

Un solo vocabulario. Ningún auto-PASS sin evidencia.

Gates are facilitators, not generators — the verdict's decider can never be empty. The engine is the source of truth (bathos gate show).

게이트는 FACILITATOR이지 generator가 아닙니다 — 판정 주체는 비어 있을 수 없습니다. 진실 원천은 엔진(bathos gate show).

Los gates son facilitadores, no generadores — quien emite el veredicto nunca puede quedar vacío. La fuente de verdad es el motor (bathos gate show).

PASS
Criteria met, no blockers → proceed to the next wave.
기준 충족, 블로커 없음 → 다음 웨이브 진입.
Criterios cumplidos, sin bloqueantes → avanzar a la siguiente wave.
CONCERNS
Conditional pass — log the non-blocking risk in _state/ and proceed.
조건부 통과 — 비차단 리스크를 _state/에 로그 후 진행.
Aprobación condicional — registra el riesgo no bloqueante en _state/ y avanza.
FAIL
Blocking defect → entry blocked; remediate and re-gate. A hook enforces it.
차단 결함 → 진입 차단; 보완 후 재게이트. 훅이 강제.
Defecto bloqueante → entrada bloqueada; remedia y vuelve a pasar el gate. Un hook lo hace cumplir.

07 · cross-project memory07 · 크로스-프로젝트 메모리07 · memoria entre proyectos

Memory that crosses projects.

프로젝트를 가로지르는 메모리.

Memoria que cruza proyectos.

Within a project, /save-session and /cold-start make a limit a pause, not a loss. Across projects, a global registry at ~/.bathos/registry/ lets a brand-new project start warm — reusing what earlier projects decided and learned.

한 프로젝트 안에서는 /save-session·/cold-start가 사용량 한도를 손실이 아닌 일시정지로 바꿉니다. 프로젝트를 가로지를 때는 전역 레지스트리 ~/.bathos/registry/가 있어, 완전히 새 프로젝트도 이전 프로젝트가 내린 결정과 배운 것을 재사용하며 warm하게 시작합니다.

Dentro de un proyecto, /save-session y /cold-start convierten un límite en una pausa, no en una pérdida. Entre proyectos, un registro global en ~/.bathos/registry/ permite que un proyecto totalmente nuevo arranque en caliente — reutilizando lo que proyectos anteriores decidieron y aprendieron.

BATHOS funciona sobre Claude Code. Instala los recursos del método en tu repo, apunta al motor y dirige el pipeline con slash commands.

# build the engine + copy the method into YOUR project
$ ./install.sh --into /abs/path/to/your-project
$ export BATHOS_BIN="$PWD/core/target/release/bathos"
$ bathos doctor            # preflight: ✓ everything wired

/route          /abs/path            # stakes → Lv0–4 (you confirm)
