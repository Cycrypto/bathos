BATHOS — 자주 묻는 질문 (FAQ)

처음 접했을 때 가장 먼저 떠오르는 질문들에 대한 빠른 답 — BATHOS가 무엇인지, 실행에 무엇이 필요한지, 비용은 얼마인지, 더 깊이 보려면 어디로 가야 하는지. 각 답은 더 자세한 내용이 필요할 때 해당 전체 문서로 안내한다.

함께 보기: 사용(USAGE-kr) · 특징(FEATURES-kr) · 비용·쿼터(QUOTA-kr) · English: FAQ-en.md · Español: FAQ-es.md

BATHOS가 정확히 뭔가?

Claude Code 위에서 도는 메서드 패키지다 — 17개 전문 역할 × 7웨이브 파이프라인 + Scale-Adaptive 라우팅 + 하드 품질 게이트, 그리고 작은 Rust 엔진. 독립 실행 앱이 아니며, 하나의 Claude Code 세션을 절제된 제품 팀으로 오케스트레이션한다.

실행에 뭐가 필요한가?

Claude Code v2.1.32+ + 실험 기능 Agent Teams(CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1), Rust 툴체인(엔진 1회 빌드), jq(안전 훅). macOS/Linux.

내 프로젝트에 어떻게 넣나?

./install.sh --into /abs/path/to/your-project 로 .claude/·assets/·modules/를 복사하고, BATHOS_BIN을 빌드된 엔진 경로로 지정한다. 전체 흐름은 USECASE-kr.md. 이후 **bathos doctor**로 배선 확인.

팀원이 무출력으로 멈췄다 — 고장인가?

거의 아니다 — 가장 흔한 원인은 코드 버그가 아니라 계정 사용량(session) 한도다. 리셋 후 재스폰하면 .agent-team/ 디스크 산출물 덕에 무손실 재개한다. QUOTA-kr.md.

서브에이전트가 시작 시 멈춘다.

.claude/settings.json을 확인한다 — hooks 블록의 주석키(예: _note)가 서브에이전트 시작을 무한 대기에 빠뜨린다. 유효 이벤트명만 둔다. **bathos doctor**가 이를 결정적으로 잡아낸다.

실행 비용은? 아끼려면?

토큰 비용은 활성 팀원 수와 레벨에 비례한다. 맞는 최저 레벨을 선택하고, 동시 팀원을 3 이하로 유지하며, 필요한 역할만 스폰하고, W4는 연기한다. 상세: QUOTA-kr.md.

"tamper-evident 감사 체인"은 실제인가, 주장인가?

실제이며 검증 가능하다: bathos audit verify가 sha256 체인을 끝까지 검증한다(hash_prev[n] == hash_self[n-1], genesis 앵커, 단조 seq). 단절 시 E-AUDIT-TAMPER + exit 1.

작업을 저장하고 새 세션에서 이어갈 수 있나?

된다. /save-session이 모든 것(머신 SSOT + 서술)을 _state/에 스냅샷하고, /cold-start가 새 세션에서 완전 복원한다. 짧은 별칭 /save·/resume. USAGE-kr.md §12.1.

왜 독립 리뷰가 테스트가 놓친 버그를 찾았나?

그게 핵심이다 — 생성 ≠ 검증. 테스트는 검사한 것만 증명하고, 독립 리뷰어(Thomas)는 저자가 보지 못한 불변식·통합 지점을 공격한다. BATHOS는 저자와 검증자를 설계로 분리한다.

새 기능(예: 보안 감사)을 어떻게 추가하나?

도메인 팩이면 플러그로 — MODULE-GUIDE-kr.md. 역할이 내 프로젝트에서 어떻게 행동하는지를 바꾸고 싶다면 team/user 오버라이드 — ROLE-GUIDE-kr.md. 코어는 슬림하게(불변식 A9).

프로덕션 준비됐나?

아직이다. v0.1.0은 초기지만 동작하며 dogfooding 검증됐다(257 테스트 + 46 훅 그린, 완전 독립 인증). 1.0 전 API·스키마·커맨드명 변경 가능. 아직 자기 자신에 대해서만 검증됐다 — 실제 외부 파일럿이 다음 마일스톤이다.

라이선스는? 이거 BMAD인가?

MIT. BATHOS는 BMAD-METHOD(MIT © 2025 BMad Code, LLC)를 정밀 역분석한 뒤 제1원리에서 독립 구현한 것으로, 그 근간이 된 선행 작업에 진심 어린 경의를 표한다. BMAD 상표는 사용하지 않는다.
